# good-notes-from-LLMs

A collection of useful lessons learned from LLM conversations, one note per topic.

## Layout

- One Markdown file per lesson, grouped in a folder per tool/topic (e.g. `rclone/`).
- Add every new note to the index in `README.md`.

## Git rules

- Claude may commit.
- Commit messages: a single line of 5–10 words, no body.
- No `Co-Authored-By` or any other attribution trailer.
- Never run `git push`. The user pushes themselves.
